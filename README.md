# Portfolio

Personal portfolio for a junior Sysadmin / DevOps engineer.

## Status

Planning phase: UX first, then UI.

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router, static export)
- React
- TypeScript

## Roadmap

- [ ] UX: sections, user flow, wireframes
- [ ] UI: design system, components
- [ ] Project scaffolding
- [ ] Content (projects, about, contact)
- [ ] Containerization (Docker)
- [ ] CI/CD pipeline
- [ ] Deployment

## Getting Started

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export to ./out
```

## Content

All content lives in `src/data/*.json` (`profile`, `about`, `experience`, `projects`, `links`). Edit or add entries there; no component changes are needed.
